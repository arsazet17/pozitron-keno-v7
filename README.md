# ПОЗИТРОН КЕНО v7.1.2

Отдельная сборка v7.1 с модулем «Чётная волна — 4 тройки / 12 чётных чисел».

## Файлы

- `index.html` — приложение.
- `even-wave.js` — живая Чётная волна и проверка прогнозов.
- `even-wave-model-v71.json` — предрасчитанная модель и результат проверки 70/30.
- `keno-history-v71.json` — база тиражей.
- `keno-update-v71.js` — обновление базы с Lucky Numbers.
- `.github/workflows/update-keno-v71.yml` — автоматическое обновление базы.
- `max-retro.js` — независимый модуль Макс Ретро.

Сборка не использует старую Netlify-функцию и не зависит от файлов приложения v7.2.
